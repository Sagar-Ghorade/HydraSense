About HydraSense

A simple system to monitor and predict groundwater levels using real DWLR data and machine learning.

Real DWLR Data

Uses government DWLR records for accurate analysis.

Machine Learning

Predicts future groundwater levels using trained models.

Better Decisions

Helps in sustainable water resource management.

Data Source

DWLR (Dynamic Ground Water Level Records)
Central Ground Water Board (CGWB), Government of India

Our Goal

To provide easy access to groundwater information so that individuals, researchers and authorities can make better decisions for sustainable water management.
